# Citation Style Language files

The `.csl` style files and `locales-en-GB.xml` in this folder come from the
[Citation Style Language](https://citationstyles.org/) project:

- Styles: <https://github.com/citation-style-language/styles>
- Locales: <https://github.com/citation-style-language/locales>

They are licensed under the [Creative Commons Attribution-ShareAlike 3.0 Unported licence](https://creativecommons.org/licenses/by-sa/3.0/),
and the authors and contributors of each style are listed inside its file.
They are included unmodified.

| File | Style |
|---|---|
| `apa.csl` | APA Style, 7th edition |
| `harvard-cite-them-right.csl` | Cite Them Right, 12th edition (Harvard) |
| `journal-of-the-indian-law-institute.csl` | Journal of the Indian Law Institute |
| `oscola.csl` | OSCOLA, 4th edition |
| `modern-language-association.csl` | MLA Handbook, 9th edition |
| `ieee.csl` | IEEE Reference Guide |
| `chicago-notes-bibliography.csl` | Chicago Manual of Style, 18th edition (notes and bibliography) |
| `chicago-author-date.csl` | Chicago Manual of Style, 18th edition (author-date) |

To update a style, download the latest version from the styles repository and replace the file.
